# Repository feature recommendations

Repository pages recommend relevant capabilities that are not configured yet:
visual review, preview seed data, explicit trigger labels, grader setup,
scheduled tasks, and repository configuration.

New repositories default main-branch health monitoring, automatic repair, and
pull-request cost footers to off. Recommendations link to the focused setup or
settings surface and disappear when the capability is configured.

For implementation details, see
`docs/engineering/architecture/repository_feature_recommendations.md`.
