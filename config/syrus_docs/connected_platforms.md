# Connected platforms

Connect a Syrus user to a Telegram or Discord identity with a linking token
that expires after 15 minutes. Linking for a platform is offered once its bot
token has been connected as an instance-owned connected account (**Admin →
Connected accounts**); the Telegram instructions show the bot's @handle, which
Syrus reads from Telegram itself.

For implementation details, see `docs/engineering/architecture/connected_platforms.md`.
