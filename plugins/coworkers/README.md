# Coworkers

Coworkers is an experimental foundation for persistent, named agents owned by
one Syrus user. It provides globally unique handles, explicit capability
grants, workspace identity, appearance, and main or side chat associations.

The plugin is installed with Syrus but disabled by default. A self-hosted
instance must enable beta mode before an administrator can enable it. Enabling
the current foundation does not add creation or execution screens yet; those
operator workflows arrive with later Coworkers capabilities.

Existing chats are unchanged. A chat without an explicit coworker association
continues to resolve to Syrus, the built-in engineer. Disabling the plugin
removes its runtime chat and mention contributions without deleting its stored
records.
