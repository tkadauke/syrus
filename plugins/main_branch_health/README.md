# Main branch health

This bundled plugin owns main-branch health repository state, settings, health-check history, and concern reports. Its accessors preserve the existing Repository and AppSetting interfaces while keeping plugin data out of core tables.

A Syrus plugin generated by `syrus plugin new`.

Run `syrus plugin test` before every push. See the [external plugin authoring guide](https://syrus.dev/docs/plugins) for the public host API, frontend build, and installation contracts.
