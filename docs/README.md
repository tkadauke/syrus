# Syrus documentation

This tree contains documentation for people who build and operate Syrus itself.
Choose a section by audience:

- [`dev/`](dev/) — contributor conventions for changing the codebase.
- [`internals/`](internals/) — architecture, data models, telemetry, audit
  storage, and internal APIs.
- [`ops/`](ops/) — running, scaling, deploying, and upgrading Syrus.
- [`plugins/`](plugins/) — authoring Syrus plugins.

Documentation about behavior needed to *use* the harness belongs in
`config/syrus_docs/`, which is searchable by chat and implementation agents on
any project. Public product documentation belongs in `website/`.
