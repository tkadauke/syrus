# Architecture

Architecture documents describe Syrus as it works now: subsystem boundaries,
data ownership, execution flow, state transitions, and cross-cutting invariants.
The maintainers of the affected subsystem own them and update them with
behavioral changes. Future designs belong in plans; durable choices and their
rationale belong in ADRs.
